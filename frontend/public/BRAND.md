# Thooriga brand assets

- `logo.png`: the user-supplied colorful paintbrush and shutter emblem on a dark background, cropped without changing the artwork. Used in the dark UI and public showcase.
- `logo-light.png`: the same emblem on its original light background, available for light-theme applications.
- `brand-icon.png`: resized dark variant for compact branded UI symbols.
- `favicon.png`: resized dark variant for the browser tab.
- The artwork is supplied by the project owner. Confirm you have rights to distribute it in a public repository.
- Non-brand functional navigation icons continue to use Lucide for clarity.
