Privacy by design

Your photos don't need our server.

The local application processes images through FastAPI and an Ollama-hosted Gemma model on your machine. It does not require a cloud photo gallery or account. We do not claim that this website performs on-device photo analysis in your browser.

Get started

Run the actual AI workspace locally.

Get the complete source repository, then install the pinned dependencies using the included scripts. Model weights are downloaded separately. The public website does not accept photos or connect to a private Ollama server.

Windows PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
ollama pull gemma3:4b
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1
# In another terminal
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-frontend.ps1

Read docs/SETUP.md, PRIVACY.md, and docs/DEPLOYMENT.md from the source repository for full instructions, requirements, and limitations.
