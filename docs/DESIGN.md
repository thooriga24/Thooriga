# Workspace redesign

The user supplied the [Lark — Nocturnal Messenger & Private Workspace reference](https://dribbble.com/shots/27768467-Lark-Nocturnal-Messenger-Private-Workspace-Web-UI-UX-Design). Dribbble returned HTTP 403 in the build environment, so the exact reference composition was not inspected or copied. The implemented direction uses a dark private-workspace layout: charcoal surfaces, restrained blue controls, compact sidebar navigation, a central photo library, and a separate creative-brief panel.

The prior landing-page hero, marketing slogans, decorative leaf logo and tagline footer were removed. Interface copy now names tasks, states, controls and privacy limitations. Event and sponsor content remains outside the product UI.

The app uses `frontend/public/logo.png`, adapted from the user's aperture reference with a red/blue ring and neutral shutter blades. A compact SVG aperture is retained as the favicon. Asset provenance is in `frontend/public/BRAND.md`.

On laptops, navigation and the creative brief appear beside the gallery. On small screens, navigation moves into a compact top bar and panels stack. Photo upload, selection, comparison, search, filters, ordering, export and privacy information are available in the responsive layout. No nonfunctional template messaging controls were added.

Screenshots in this directory are browser captures of the application. A sample-filled screenshot, when provided, shows only the attributed public-domain photograph without model-generated assessments. No precomputed AI output is presented as live inference.
